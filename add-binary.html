67. Add Binary — column addition from the right, with a carry

Exactly like adding numbers by hand: start at the rightmost digit of each string, add the two digits plus the carry, write down total % 2, carry total // 2 to the next column, and move left. Keep going while either string has digits or a carry is left.

      Why % 2 and // 2? In binary a column can total 0, 1, 2 or 3 (two digits plus a carry).
      The digit written is the remainder after dividing by 2; the carry is how many 2s fit.

      Why or carry in the loop? When both strings run out, a carry of 1 still has to be written as a new leftmost digit.
      That's how "11" + "1" becomes 3 digits: "100".

      Why reversed? Digits are produced right-to-left, so res is backwards. Appending and reversing once
      is O(n), but inserting at the front each time would be O(n²).
    

    

      
TimeO(max(m, n))
        m = len(a), n = len(b). The loop runs once per column: max(m, n) times, plus at most one more for a final carry. Each pass is O(1), and the final reverse and join is O(max(m, n)).

      
SpaceO(max(m, n))
        res holds one character per output digit, at most max(m, n) + 1. The answer string is the same size. Apart from that, only i, j, carry and total.

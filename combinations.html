77. Combinations — Backtracking (choose, explore, un-choose)

Build path one number at a time, always picking numbers larger than the last one, so each set is produced exactly once. When path has k numbers, save a copy. Skip starting numbers that leave too few numbers to finish.

Recursion tree (each node = the number just added to path)

TimeO(k·C(n,k))
        There are C(n,k) combinations and each is copied in O(k). Thanks to pruning, every call leads to at least one saved combination, so there are at most k·C(n,k) + 1 calls.

      
SpaceO(k)
        Extra memory is the recursion stack plus path, both at most k deep. The output itself holds C(n,k) lists of length k, so O(k·C(n,k)) if you count it.

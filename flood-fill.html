733. Flood Fill — DFS on a grid

Start at (sr, sc), remember its original color, and spread to the 4 neighbours (down, up, right, left) that still have that color, repainting each one.

      Why check original == color first? If they're equal, painting changes nothing, so a painted cell would still look
      "original" and the DFS would bounce between neighbours forever. Otherwise, painting a cell is what marks it as visited:
      once it has the new color, image[r][c] != original stops any later call there.

      Diagonals don't count. Only the 4 edge-sharing neighbours are explored.

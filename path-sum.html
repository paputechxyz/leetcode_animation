112. Path Sum — DFS, subtracting as we go

Instead of adding up the path, each call subtracts its node's value from the target and passes the remaining amount down. A leaf succeeds if nothing is left.

Tree

current call waiting on a child call leaf, remaining = 0 ✓ leaf, remaining ≠ 0 ✗ returned never checked (short-circuit) t=… target passed into that call

Code


    

      Why subtract? Each call only needs to know "how much is still missing". At a leaf, the path works exactly when that is 0.

      Why leaves only? The path must end at a leaf. A node with one child is not a leaf, and its missing child returns
      False, so a path can't stop halfway.

      Short-circuit: a or b never evaluates b if a is True,
      so once a path is found, the rest of the tree is skipped.

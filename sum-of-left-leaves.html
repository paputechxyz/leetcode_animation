404. Sum of Left Leaves — DFS with an is_left flag

A node counts only if it is a leaf and it is the left child of its parent. Each call is told which side it came from.

Tree

current call waiting on child calls left leaf → counted right leaf / root leaf → 0 returned

Code


    

      Why the flag? A leaf can't tell by itself whether it's a left child — only the parent knows.
      So the parent passes True when going left and False when going right.
      The root starts with False, because it has no parent.

      The small badges on the tree show what each call returned. A parent returns left result + right result.

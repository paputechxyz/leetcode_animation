190. Reverse Bits — pop from the right of n, push onto the right of result

Repeat 32 times: take n's lowest bit (n & 1), shift result left to make room and drop the bit in, then shift n right to expose the next bit. The first bit taken gets pushed left 31 more times, so it ends up at the far left: the bits come out reversed.

32-bit registers (bit 31 on the left … bit 0 on the right)

1 bit 0 bit bit being moved now already placed in result (label = original bit #) already taken from n zero shifted in by >>

Code


    

      
n & 1Reads the lowest bit of n: 1 if n is odd, 0 if it's even.

      
result << 1Shifts every bit of result one place left (×2), which leaves a 0 at the right end.

      
| bitWrites the bit into that empty right-end slot.

      
n >>= 1Shifts n one place right (÷2). The bit just used falls off, and the next one moves into the lowest slot.

    

    

      
TimeO(1)
        The loop always runs exactly 32 times (the bit width b), whatever the value of n, and each pass is a few O(1) bit operations. More generally that's O(b).

      
SpaceO(1)
        Only two integers, n and result, plus the loop counter. No arrays or strings.

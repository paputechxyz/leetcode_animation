226. Invert Binary Tree — swap, then recurse

At every node, swap its left and right children, then do the same inside each child. When every node has been swapped, the whole tree is a mirror image.

      Why does this work? Mirroring a tree = the mirrored right subtree goes on the left, and the mirrored left subtree goes on the right.
      Swapping first and then recursing into both children does exactly that, one level at a time.

      Swap is one line in Python: a, b = b, a evaluates the right side first, so no temp variable is needed.

      Leaves swap None ⇄ None (no visible change) and their two invertTree(None) calls return immediately.
    

    

      
TimeO(n)
        Every node is visited exactly once and does one O(1) swap. The n + 1 invertTree(None) calls add only constant work each.

      
SpaceO(h)
        The recursion stack is as deep as the tree's height h: O(log n) when balanced, O(n) for a chain. The tree is inverted in place, so there's no extra copy.

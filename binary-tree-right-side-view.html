199. Binary Tree Right Side View — DFS, right child first

Visit the right child before the left. Then the first node reached at each depth is the rightmost one, the one you'd see standing to the right of the tree.

      The trick is depth == len(result). result has one entry per depth already seen, so
      len(result) is the first depth with no entry yet. If the current node's depth equals it, this is the
      first node reached at this depth.

      Why first = rightmost: because dfs(node.right) runs before dfs(node.left), every node
      further right at the same depth is visited earlier. Later nodes at that depth are hidden behind it.

      Left nodes can still show up if nothing on the right reaches that deep.
    

    

      
TimeO(n)
        Every node is visited exactly once, hidden ones included. Each visit does O(1) work: one comparison and at most one append.

      
SpaceO(h)
        The recursion stack is as deep as the tree's height h: O(log n) when balanced, O(n) for a chain of nodes. result holds h + 1 values, so it's O(h) as well.

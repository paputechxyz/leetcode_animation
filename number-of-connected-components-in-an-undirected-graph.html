323. Number of Connected Components in an Undirected Graph — Union-Find

Start with every node as its own component (n of them). For each edge, find the root of both ends. Different roots mean the edge connects two separate components: merge them and subtract 1. The same root means they're already connected, so skip the edge.

      Why roots? Each component is stored as a tree of parent pointers, and the root names the component.
      Two nodes are connected exactly when find gives them the same root.

      Union just points one root at the other (parent[root_b] = root_a), which merges the whole tree in one step.

      Path halving (line 7): while walking up, each node is re-pointed to its grandparent, so later finds have shorter paths to climb.
    

    

      
TimeO(n + E·log n)
        E = number of edges. O(n) to build parent, then 2 finds per edge. With path halving alone each find is amortized O(log n). Adding union by rank as well brings it to O(α(n)), effectively constant.

      
SpaceO(n)
        The parent list has one entry per node. find is iterative, so there's no recursion stack.
